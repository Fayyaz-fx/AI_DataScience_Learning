# 🎓 Learning — AI & Data Science

A personal learning repository documenting my journey through Artificial Intelligence
and Data Science. This repo contains code, notebooks, exercises, and notes from
various courses, books, and learning resources.

---

## 📚 What's Inside

Each learning resource has its **own dedicated branch**, keeping code, notebooks,
and setups isolated and organised.

| Branch | Resource | Type |
|--------|----------|------|
| `course/LLM Engineering Master Class by Dr. Ryan Ahmad` | Udemy Course | Course |

---

## 🌿 Branch Naming Convention

Branches follow a consistent naming pattern:

- `course/resource-name` — for online courses (Udemy, Coursera, etc.)
- `book/resource-name` — for books
- `project/project-name` — for personal projects and experiments

---

## 🛠️ Tech Stack

Languages and tools used across this repo:

- **Languages:** Python, SQL
- **Libraries:** NumPy, Pandas, Matplotlib, scikit-learn, PyTorch, TensorFlow
- **Tools:** Jupyter Notebook, VS Code, Google Colab

---

## 🚀 How to Use

Clone the repo and switch to any branch to explore that resource:

```bash
git clone https://github.com/your-username/AI_DataScience_Learning.git
cd AI_DataScience_Learning

# Switch to a specific course
git checkout course/course-name
```
